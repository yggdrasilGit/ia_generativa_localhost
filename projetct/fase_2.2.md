Se a ideia é **expandir a Fase 2** antes de ir para a Fase 3, eu dividiria assim:

* **Fase 2.0** – Interface básica (ChatGPT Clone)
* **Fase 2.1** – Experiência de conversa
* **Fase 2.2** – Interface profissional (UX e produtividade)
* **Fase 2.3** – Personalização
* **Fase 2.4** – Preparação para módulos futuros
* **Fase 2.5** – Infraestrutura do frontend

## Fase 2.2 – Interface Profissional

O foco aqui é fazer a interface parecer um software premium.

### 1. Paleta de comandos (Command Palette)

Ao pressionar:

```text
Ctrl + K
```

Abre uma caixa de pesquisa para:

* Nova conversa
* Procurar conversas
* Trocar modelo
* Abrir configurações
* Limpar chat
* Ir para biblioteca
* Abrir memória
* Abrir agentes

---

### 2. Barra lateral recolhível

```
←
```

Esconde a sidebar.

```
→
```

Mostra novamente.

---

### 3. Favoritos

Separar:

```text
⭐ Favoritos

──────────────

Histórico
```

---

### 4. Tags

Cada conversa pode receber:

```
Direito

Python

Estatística

Projeto IA

Física
```

Depois será possível filtrar por tag.

---

### 5. Pastas

Exemplo:

```
📁 Concursos

📁 Faculdade

📁 Projeto IA

📁 Trabalho
```

---

### 6. Pesquisa avançada

Pesquisar por:

* Palavra
* Data
* Modelo utilizado
* Tag
* Pasta

---

### 7. Mensagens fixadas

Você fixa mensagens importantes.

Exemplo:

```
📌 Arquitetura do projeto

📌 Prompt principal

📌 Constituição
```

---

### 8. Exportação

Exportar conversa para:

* Markdown
* PDF
* DOCX
* HTML
* JSON

---

### 9. Importação

Importar:

* Conversas antigas
* Backup
* JSON

---

### 10. Atalhos de teclado

| Atalho           | Ação                     |
| ---------------- | ------------------------ |
| Ctrl + K         | Paleta de comandos       |
| Ctrl + N         | Nova conversa            |
| Ctrl + F         | Pesquisar conversa       |
| Ctrl + B         | Mostrar/esconder sidebar |
| Ctrl + ,         | Configurações            |
| Ctrl + Shift + C | Copiar última resposta   |
| Esc              | Cancelar geração         |

---

## Resultado da Fase 2.2

Ao final dessa etapa, o Yggdrasil AI terá uma interface madura e preparada para crescer, oferecendo uma experiência de uso muito próxima de plataformas comerciais. Quando você iniciar a Fase 3 (histórico e autenticação), a base visual e de navegação já estará pronta, permitindo focar apenas nas funcionalidades do backend sem precisar redesenhar a interface.
